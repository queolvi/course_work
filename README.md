# WIMS - Warehouse Inventory Management System (Система складского учёта)
____________
Это публичный репозиторий для отображения работы над курсовой работой и демонстрации результата, вместе с исходным кодом
## Тема курсовой работы:
### "Создание модуля для складского учёта с резервированием и контролем сроков годности" ###
____________
## Целевая установка:
### "Создание модуля для складского учёта с резервированием и контролем сроков годности, обеспечивающего автоматизацию работы, процесс приёмки, хранения товаров, механизмы валидации и защиты данных, и формирование отчётности на основе актуальных данных. Модуль должен сократить время работы, заменяя бумажный учёт и сократить количество ошибок при работе с данными"
____________
## Задания для курсовой работы
    1. Проведение анализа предметной области: нахождение цели, задач и постановка бизнес-требований проекта
    2. Формирование требований к программному модулю и составление технического задания на разработку
    3. Проектирование модуля: выбор программной архитектуры и построение UML диаграмм
    4. Проектирование Базы Данных: выведение инфологической и даталогической модели, ER-диаграммы сущностей и проведение процесса нормализации
    5. Выбор технологического стека разработки: выбор основного языка программирования и вспомогательные технологии (БД, фреймворки и библиотеки)
    6. Осуществление программной реализация модуля: разработка структуры проекта, классов, пользовательского интерфейса, авторизации и разграничение прав доступа по ролевой системе
    7. Тестирование и отладка модуля: разработка плана тестирования и тест-кейсов, проведение модульного и функционального тестирования
